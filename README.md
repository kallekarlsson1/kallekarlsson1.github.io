# kallekarlsson1.github.io

Personal site. Plain Jekyll, no theme.

- Bio and links: `_config.yml` (`description`, `nav`)
- Posts: `_posts/` (set `published: true` to show one)
- Other pages: `projects.md`, `cv.md`, `contact.md`
- Look: `assets/css/style.css`; mountain lines: `_includes/mountains.html`

Run locally: `bundle install && bundle exec jekyll serve` → http://localhost:4000
